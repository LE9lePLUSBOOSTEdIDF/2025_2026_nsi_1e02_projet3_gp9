# 2025_2026_nsi_1e02_projet3_gp9

Objcectifs : Créer un jeu de type plateforme en python avec du scroll, avec des ennemis qui pourchassent le joueur, on a une arme qui tire un projectile

Cahier des charges :

Ambiance du jeu : sombre, médiévale fantastique ( hollow knight , dark souls )
Personnages : 
Ennemis : chevaliers squelettes, chef des chevaliers squelettes qui en fait spawn qui s'appelle David Goggins , zombies

Partie technique :

Avoir les props
Rendre belle l'interface graphique
Rendre beau le menu
Faire du scroll ( l'écran suit le joueur )
Faire une attaque au corps à corps
Adapter le saut aux plateformes
Rajouter des plateformes
Faire une ambiance sonore ( musique, bruitages )

Les changements à faire :
Changer la fonction "forward" des monstres en quelque chose qui suit le joueur précisément
Le jeu accélère tout seul ?
Optimiser le jeu car il bug trop rapidement lorsqu'on lance plein de projectiles
